# Exercícios de Condicionais em Python

## Sobre o projeto

Repositório com exercícios práticos desenvolvidos durante meus estudos de programação em Python.

O objetivo é praticar lógica de programação, estruturas condicionais e resolução de problemas utilizando a linguagem Python.

## Conteúdos praticados

- Estruturas condicionais (`if`, `elif` e `else`).
- Operadores lógicos e relacionais.
- Entrada e saída de dados.
- Operações matemáticas.
- Condicionais aninhadas.

## Exercícios desenvolvidos

- Cálculo de média de notas.
- Resolução de equações do segundo grau.
- Cálculo e classificação do IMC.
- Avaliação de funções matemáticas.
- Classificação de triângulos.
- Calculadora com operações básicas.
- Cálculo de diárias.
- Exercício de cálculo de valores de academia.

## Tecnologia utilizada

- Python 3

## Objetivo

Desenvolver minha base em programação e aprimorar o raciocínio lógico, como parte da preparação para atuar na área de desenvolvimento de software e Backend.
